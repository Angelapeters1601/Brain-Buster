# 🧠 BrainBuster Quiz App

BrainBuster is a sleek, interactive quiz application built with React and Vite. Designed to challenge and educate, it allows users to select their preferred topic, number of questions, and difficulty level—then puts their knowledge to the test with real-time scoring, progress tracking, and time-bound quizzes.

> ✅ Reviewed and praised by a certified Udemy React instructor.

## 🚀 Live Demo

👉 [brain-buster-six.vercel.app](https://brain-buster-six.vercel.app)

---

## 🛠️ Tech Stack

- **Framework:** React.js (with Vite)
- **State Management:** `useReducer` hook
- **Animations:** Framer Motion
- **Styling:** CSS
- **APIs:** Trivia API for dynamic quiz data
- **Deployment:** Vercel

---

## ✨ Features

- 🧩 Choose **quiz topic**, **difficulty level**, and **number of questions**
- 🕒 Smart **timer** based on selected difficulty and question count
- ✅ **Real-time progress tracking**
- 🧮 **Score summary and remark** at the end
- 🔁 Option to **restart the quiz**
- 💅 **Clean and modern layout**
- 📱 **Responsive design** for all devices
